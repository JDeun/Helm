# Helm v0.9.3

Helm v0.9.3 adds a release-version consistency check and tightens README release-note readability.

## Added

- `scripts/release_version_check.py` verifies that `pyproject.toml`, `setup.py`, `CITATION.cff`, README release banners, `CHANGELOG.md`, and `docs/releases/<version>.md` agree on the current release version.
- Regression tests cover both the passing path and a mismatched `setup.py` version.

## Changed

- README release details now show only the latest release notes plus a link to the full `docs/releases/` directory.

## Verification

- `python3 scripts/release_version_check.py`
- `python3 -m pytest tests/test_release_version_check.py -q`
