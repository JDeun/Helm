# Helm v0.9.1

Helm v0.9.1 adds a post-write artifact validation gate for workflows that generate durable files, notes, reports, or reusable state.

## Added

- `artifact_validation` contract support for skill-local `contract.json` files.
- `helm harness record-evidence --write-validation-json` for recording workspace validator results as `memory_capture.write_validation`.
- Postflight enforcement that fails artifact validation when `ok` is not true or no checked paths are recorded.
- Skill scaffolding support for a `Post-write validation contract` section in new `SKILL.md` files.
- Manifest quality audit warnings when a skill requires artifact validation but does not document the boundary in `SKILL.md`.

## Docs

- Updated adaptive harness documentation with the artifact validation gate.
- Updated task finalization documentation with write-validation examples.
- Updated skill quality guidance so artifact-producing skills document validator, checked paths, and failure behavior.

## Tests

- Full suite: 402 tests passing.
