# Helm v0.9.2

Helm v0.9.2 documents artifact-specific validation discipline for Obsidian-backed agent workspaces.

This is a documentation release. It does not change Helm runtime behavior.

## Docs

- Added minimal-diff discipline to execution-profile guidance for `workspace_edit` and `risky_edit`.
- Clarified that file changes need a named verification gate before a task is treated as complete.
- Added Obsidian-specific post-write validation examples for Markdown notes, Bases, and Canvas files.
- Documented how an Obsidian validator can emit Helm-compatible `write_validation` evidence.
