# Helm v0.9.4

Helm v0.9.4 adds release-smoke packaging validation and single-source package versioning.

## Added

- `scripts/release_smoke.sh` now verifies release-version consistency, builds wheel/sdist artifacts, and validates package metadata.

## Changed

- Removed the legacy `setup.py` packaging shim so `pyproject.toml` is the single package version source.
- README release links now show a compact latest/recent view with the full release-note directory linked for history.

## Verification

- `python3 scripts/release_version_check.py`
- `python3 -m pytest -q`
- `python3 -m build --sdist --wheel`
- `python3 -m twine check dist/helm_agent_ops-0.9.4*`
